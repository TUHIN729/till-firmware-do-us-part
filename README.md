A single wedding vow spoken by a robot at its own wedding: one sentence, under 200 characters, funny and heartfelt at once. It promises love in every frame rate, through every glitch and lag spike, until its memory banks forget everything except one name.

## Run it

```sh
python3 main.py
```

This writes the vow to `/output/entry.txt`.
